# Proposal: LittleStar Phase 2 — 渐进式年级解锁 + 学习报告 + 入学测评

## Summary

在 Phase 1（幼儿园中班/大班）基础上，新增三大核心功能：
1. **渐进式年级解锁**：单科目独立解锁，从中班到小学六年级按需扩展，知识点大纲参考教育部课标
2. **学习报告**：按年级维度展示的周/月报告，含时长统计、掌握趋势、成就里程碑、薄弱提醒、年级进度
3. **入学测评**：首次使用和每次年级解锁时自动触发，10-15 题/科目，确定起始知识点跳过已掌握内容

## Motivation

- Phase 1 仅覆盖幼儿园中班/大班，孩子学完后无后续内容
- 家长缺乏系统的学习进度可视化工具
- 新年级开始时需要评估孩子已有水平，避免重复学习
- 小学内容扩展需要科学的课标依据，不能随意编排

## Scope

### In Scope (Phase 2)

- 年级体系扩展：GradeLevel 类型从 2 级扩展到 8 级（中班→六年级）
- 年级解锁引擎：单科目独立解锁 + 可配置掌握度阈值（默认 80%）
- 知识点大纲系统：小学 1-6 年级数学/语文/英语知识点预定义（参考 2022 课标）
- 大纲按需加载：解锁新年级时才加载该年级的知识点和模板
- 入学测评引擎：10-15 题/科目，自适应题目选择，确定起始知识点
- 学习报告系统：周/月报告数据聚合 + 可视化组件
- 报告维度：学习时长、掌握趋势图、成就里程碑、薄弱知识点、年级进度

### Out of Scope

- 后端服务器 / 云同步
- iOS / Android 原生打包
- 支付系统
- 多用户 / 教师端
- 社交功能（虚拟宠物伙伴等）

## Impact

- **数据模型变更**：GradeLevel 类型扩展、新增 GradeUnlock / PlacementTest / ReportData 表
- **文件变更**：预计新增 30-40 个文件（大纲数据、引擎、组件、测试）
- **依赖**：可能新增图表库（如 recharts）用于报告可视化
- **风险**：知识点大纲数据量较大（6 个年级 × 3 科目），需要分模块按需加载

## Decision Log

| 决策 | 选项 | 结论 | 原因 |
|------|------|------|------|
| 年级解锁方式 | 一次全部 vs 渐进式 | 渐进式按需 | 用户要求，学完当前年级再扩展下一级 |
| 解锁粒度 | 全科同步 vs 单科独立 | 单科独立 | 允许数学进一年级但语文仍在大班 |
| 掌握度阈值 | 固定80% vs 可配置 | 可配置，默认80% | 家长可根据孩子情况调整 |
| 内容生成 | 全AI生成 vs 预定义大纲+AI题目 | 预定义大纲+AI题目 | 大纲参考课标保证权威，题目AI生成保证多样 |
| 课标参考 | 自编 vs 教育部2022课标 | 2022课标 | 数学/语文/英语课程标准 + 3-6岁发展指南 |
| 学习报告维度 | 全局 vs 按年级 | 按年级 | 用户明确要求 |
| 入学测评时机 | 仅首次 vs 每次解锁 | 每次解锁新年级 | 确定新年级起始知识点 |
| 测评目的 | 水平评估 vs 确定起始点 | 确定起始知识点 | 跳过已掌握内容 |
| 测评规模 | 5题 vs 10-15题 | 10-15题/科目 | 5-8分钟完成，足够准确 |
| 图表库 | Chart.js vs Recharts | Recharts | React 原生，声明式，TypeScript 友好 |
