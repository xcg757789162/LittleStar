# Functional Requirements: LittleStar Phase 1

## FR-001: 项目基础设施

- 使用 Vite + React 18 + TypeScript 初始化项目
- 配置路径别名、ESLint、Prettier
- 配置 Vitest + Testing Library
- 建立 Dexie.js 数据库 schema 和 migration
- 建立 Zustand store 架构
- 配置 .env 环境变量（AI API Key）

## FR-002: 数据模型与知识图谱

- 实现所有核心数据表（Child, KnowledgeNode, LearningRecord, MasteryRecord, Question, QuestionTemplate, Achievement, DailySession）
- 实现知识图谱结构：节点间前置/后续依赖关系
- 种子数据生成：
  - 数学：数字认知(1-20)、数数、比大小、10以内加减法、图形认识
  - 语文：拼音声母韵母、50-100个常见汉字、简单儿歌
  - 英语：26个字母、基础单词(动物/颜色/水果/数字)

## FR-003: 自适应学习引擎

- 规则引擎：根据年龄、掌握率、学习历史动态选择题目
- 掌握率计算：基于艾宾浩斯遗忘曲线 + 连续正确率的综合算法
- 自适应路由：根据当前掌握状态推荐下一个最优知识点
- 复习调度器：间隔重复算法（SM-2 变体），自动安排复习
- 知识点解锁：前置知识掌握率达到阈值自动解锁后续节点

## FR-004: 学习界面

- 闪卡模式：大图+文字+语音，适合认知类学习
- 选择题模式：2-4个选项，大按钮，图文并茂
- 手写/涂鸦板：Canvas 实现，支持汉字/数字书写练习
- 语音互动：语音出题、语音回答、语音鼓励
- 即时反馈动画：正确→星星/烟花，错误→温柔引导重试
- 每日学习流程：开始→选科目→自适应出题→学习→结束奖励

## FR-005: AI 教师集成

- 通义千问 Provider 抽象层（OpenAI 兼容接口）
- AI 对话界面：气泡式对话，AI 老师头像
- 错误分析：AI 分析孩子的错误模式，提供个性化建议
- 鼓励系统：根据学习状态动态生成鼓励语
- AI 出题：按模板+约束条件调千问 API 生成题目
- 安全过滤：过滤不适合幼儿的 AI 输出内容

## FR-006: TTS/STT 语音系统

- CosyVoice TTS：AI 老师声音，温暖友好的音色
- Paraformer STT：识别幼儿语音回答
- 语音控制：音量、语速可调
- 离线降级：网络不可用时使用浏览器原生 Web Speech API

## FR-007: 家长功能

- PIN 码验证：4位数字，区分家长和孩子操作
- 家长仪表盘：学习时长、完成量、正确率概览
- 学习报告：每日/每周报告，知识点掌握情况可视化
- 设置管理：每日学习时长限制、科目偏好、难度调整

## FR-008: 成就系统

- 星球收集：每个知识领域对应一颗星球，掌握后点亮
- 连续学习奖励：连续 N 天学习解锁特殊徽章
- 里程碑成就：完成特定数量题目/达到特定掌握率
- 成就展示：星空地图 UI，动画点亮效果

## FR-009: PWA 与离线支持

- Service Worker 配置（Workbox）
- 静态资源缓存策略
- API 响应缓存（AI 生成内容）
- 离线学习模式：使用已缓存的题目
- 数据同步策略：上线后同步本地学习记录

## FR-010: 多科目与内容系统

- 科目路由：数学/语文/英语独立学习路径
- AI 出题模板系统：可配置的年级/难度/题型模板
- 内容包架构：预留远程下载新内容包的能力
- 答案验证：数学自动计算验证，语文拼音匹配，英语拼写匹配
