# Spec: 知识点大纲体系（课标参考）

## Overview

为小学 1-6 年级（数学/语文/英语）定义预制知识点大纲，参考教育部 2022 年版义务教育课程标准。大纲以静态数据模块组织，按需加载。

## Requirements

### R1: 大纲数据结构

```typescript
/** 年级大纲定义 */
interface GradeCurriculum {
  gradeLevel: GradeLevel
  subject: Subject
  version: string              // 大纲版本（如 '2022-v1'）
  reference: string            // 参考标准名称
  modules: CurriculumModule[]
}

/** 知识模块（大纲的一个章节） */
interface CurriculumModule {
  id: string
  name: string                 // 如 "20以内加减法"
  description: string
  order: number
  knowledgeNodes: CurriculumKnowledgeNode[]
}

/** 大纲中的知识点定义 */
interface CurriculumKnowledgeNode {
  id: string                   // 如 'math-g1-add-within-10'
  name: string
  description: string
  difficulty: number           // 1-10
  contentTypes: ContentType[]  // 支持的题型
  prerequisites: string[]      // 前置节点 ID
  templatePrompts: {
    type: QuestionType
    prompt: string             // AI 出题 prompt
    constraints: Record<string, unknown>
  }[]
}
```

### R2: 数学大纲（1-6年级）

参考《义务教育数学课程标准（2022年版）》：

**一年级**：
- 1-5的认识和加减法 → 6-9的认识和加减法 → 11-20各数 → 20以内退位减法
- 100以内数的认识 → 100以内加减法
- 认识物体和平面图形 → 图形拼组
- 认识钟表 → 认识时间
- 位置（上下前后左右）
- 找规律、分类

**二年级**：
- 表内乘法（2-9的口诀）→ 表内除法
- 100以内加减法（二）→ 万以内数的认识
- 长度单位（厘米、米）→ 克和千克
- 角的初步认识 → 观察物体
- 统计（条形图）

**三年级**：
- 多位数乘一位数 → 除数是一位数的除法 → 两位数乘两位数
- 分数/小数初步认识
- 测量（毫米/分米/千米/吨）→ 面积
- 四边形/周长 → 年月日/时分秒
- 位置与方向 → 统计/可能性

**四年级**：
- 大数的认识 → 三位数乘两位数 → 除数是两位数的除法
- 小数的意义和性质 → 小数加减法
- 角的度量 → 平行四边形和梯形 → 三角形
- 四则运算/运算定律
- 统计（折线图）

**五年级**：
- 小数乘除法 → 简易方程
- 因数与倍数 → 分数的意义和性质 → 分数加减法
- 多边形面积 → 长方体和正方体
- 观察物体 → 图形的变换
- 统计与可能性

**六年级**：
- 分数乘除法 → 百分数 → 比和比例
- 圆 → 圆柱与圆锥
- 位置（数对）→ 负数
- 统计（扇形图）→ 综合复习

### R3: 语文大纲（1-6年级）

参考《义务教育语文课程标准（2022年版）》：

**一年级**（第一学段）：
- 汉语拼音：声母韵母声调、整体认读、拼读
- 识字与写字：800字认读/400字书写、基本笔画、笔顺规则
- 阅读：朗读课文、理解词句、儿歌童谣、浅近古诗
- 写话：写自己想说的话

**二年级**：
- 识字与写字：1600字认读/800字书写、偏旁部首、查字典
- 阅读：默读、积累词语、童话寓言故事、古诗背诵50篇
- 写话：标点使用（逗号句号问号感叹号）

**三年级**（第二学段）：
- 识字与写字：2500字、硬笔楷书
- 阅读：段落理解、初步把握文章主要内容
- 习作：观察日记、看图写话升级

**四年级**：
- 阅读策略：提问、预测、联结
- 篇章理解：把握文章主旨
- 习作：记叙文（写事写人）

**五年级**（第三学段）：
- 3500字认读
- 文体辨识：记叙文、说明文
- 阅读鉴赏：体会作者表达
- 习作：说明文写作

**六年级**：
- 综合阅读能力
- 文学常识
- 议论文入门
- 综合写作

### R4: 英语大纲（1-6年级）

参考《义务教育英语课程标准（2022年版）》：

**一年级**（预备级）：
- 26个字母认读与书写
- 自然拼读入门（辅音+短元音）
- 50个基础词汇（数字1-10、颜色、身体部位）
- 听说启蒙（课堂用语、简单问候）

**二年级**（预备级）：
- 自然拼读进阶（长元音、常见组合）
- 100个词汇（动物、水果、家庭成员、文具）
- 简单句型（This is... / I like... / I have...）
- 日常对话（自我介绍、表达喜好）

**三年级**（1级）：
- 200词汇
- 基础句型（一般疑问句、特殊疑问句）
- 日常话题：家庭、学校、食物、天气
- 听说读入门

**四年级**（1级）：
- 400词汇
- 一般现在时
- 简单阅读理解
- 基础写句

**五年级**（2级）：
- 600词汇
- 现在进行时、一般过去时
- 短文阅读
- 简单写作（3-5句）

**六年级**（2级）：
- 800词汇
- 综合时态运用
- 篇章阅读理解
- 应用写作（书信、日记）

### R5: 大纲文件组织与加载

- 每个年级每个科目一个 TypeScript 模块文件
- 使用 `export const` 导出 `GradeCurriculum` 对象
- 通过动态 `import()` 实现按需加载
- 加载入口：`src/curriculum/index.ts` 提供 `loadCurriculum(grade, subject)` 函数

## Acceptance Criteria

- [ ] 6个年级 × 3个科目 = 18个大纲模块文件
- [ ] 每个大纲至少覆盖 8-12 个核心知识点
- [ ] 知识点之间有正确的前置关系
- [ ] 动态 import 按需加载
- [ ] 知识点 ID 全局唯一，跨年级可追溯
