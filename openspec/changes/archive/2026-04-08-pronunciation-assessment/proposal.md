# Proposal: 发音评分与纠音反馈

## Summary

为 LittleStar 幼儿 AI 学习平台新增**英语发音评估与纠音教学**能力。通过接入讯飞口语评测（ISE）API 实现音素级发音评分，结合「渐进式纠音教学循环」（C2 慢速重试 → C1 分音节拍手节奏教学），为 4-5 岁幼儿提供完整的发音练习与纠正体验。

## Motivation

- 英语学习中「读」（朗读/发音）是与「听」「写」并重的核心能力，当前平台仅有基础 TTS/STT，**无发音评分和纠音反馈**
- 4-5 岁幼儿发音不标准是正常现象，需要**宽容评分 + 温和引导**的纠正方式，而非严格打分
- PRD 中定义 ASR + 跟读评分为 P0 必须功能（N9），技术架构文档已设计 `scorePronunciation()` 接口但尚未实现
- 现有代码仅有 Paraformer STT 基础识别（`stt.ts`），无法提供音素级评估和纠音反馈

## Scope

### In Scope

- **发音评估抽象接口层**：`PronunciationAssessmentProvider` 接口 + 可插拔后端策略模式
- **讯飞口语评测（ISE）后端实现**：音素级评分、幼儿模式支持
- **基础文本匹配降级方案**：API 不可用时的兜底（STT 识别结果 vs 期望文本）
- **幼儿宽容评分策略**：`CHILD_SCORING_ADJUSTMENTS`（40 分起算、星级阈值 [40,55,70,85,95]、永不给 0 星）
- **渐进式纠音教学循环**：跟读 → 评分 → C2 慢速重试（≤2 次）→ C1 分音节拍手节奏教学 → 最终评分
- **温和引导型反馈模板库**：按星级 + 音素问题的模板拼接（先肯定做对的，再引导薄弱点）
- **英文音节拆分引擎**：单词 → 音节数组（用于 C1 分音节教学）
- **发音练习 UI 组件**：星星评分动画、纠音引导 UI、分音节高亮
- **学习记录集成**：发音评分写入学习进度数据

### Out of Scope

- 第二个评测后端实现（Azure/火山/其他，后续扩展时再加）
- 发音进步趋势分析（跟踪某个单词的发音改善曲线）
- 家长发音报告（周报中展示发音弱点统计）
- 中文发音评测（本次仅覆盖英语）

## Impact

- **用户**：幼儿园中班（4-5 岁）英语学习场景
- **新增文件**：~9 个新文件（服务层 + 组件层）
- **修改文件**：~3 个（types/models.ts、stores/uiStore.ts、services/voice/index.ts）
- **新增依赖**：讯飞口语评测 SDK/API
- **风险**：
  - 幼儿语音识别准确率天然较低（缓解：宽容评分策略 + 降级方案）
  - 讯飞 API 延迟可能影响体验（缓解：文本匹配降级 + 评分缓存）
  - 分音节教学对 4 岁可能过于抽象（缓解：用拍手节奏游戏化包装，不讲音节概念）

## Decision Log

| 决策 | 选项 | 结论 | 原因 |
|------|------|------|------|
| 评分后端选型 | Azure / 讯飞 / 火山 MDD | **讯飞口语评测（ISE）** | 国内教育场景占有率高，有幼儿模式，中英文双语支持 |
| 架构模式 | 直接集成 vs 抽象接口层 | **抽象接口层** | 避免厂商锁定，已有 ASRService 接口设计基础，后续可无缝切换 |
| 纠音流程 | 一次跟读 / 纠正重试 / 分音节教学 | **C2+C1 结合**（渐进式） | C2 慢速重试作为第一道防线，C1 分音节作为深度纠音 |
| 分音节交互 | 直接讲音节 / 拍手节奏 / 慢速重复 | **C1 拍手节奏 + C2 慢速重复结合** | 拍手游戏化适合幼儿，不需要理解"音节"概念 |
| 反馈风格 | 纯鼓励 / 温和引导 / 教学分析 | **温和引导型** | 先肯定做对的再引导薄弱点，符合幼教三明治反馈法 |
| 反馈生成 | 模板拼接 / LLM 生成 | **模板拼接** | 快、稳定、可控，适合幼儿场景 |
| 通过阈值 | 60 / 70 / 80 分 | **70 分（≥3 星）** | 幼儿宽容策略，平衡鼓励与进步 |
| 最低评分 | 0 / 20 / 40 分 | **40 分（1 星）** | 低于 40 视为"没说"，永不给 0 星保护自信心 |
