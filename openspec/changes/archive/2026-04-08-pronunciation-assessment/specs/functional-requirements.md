# Functional Requirements: 发音评分与纠音反馈

## FR-001: 发音评估抽象接口层

### 描述
实现可插拔的发音评估服务接口，支持多后端切换（策略模式）。

### 要求
- **FR-001.1**: 定义 `PronunciationAssessmentProvider` 接口，包含 `scorePronunciation()` 和 `checkAvailability()` 方法
- **FR-001.2**: 实现服务工厂 `createAssessmentProvider()`，按优先级选择可用后端（讯飞 ISE → 文本匹配降级）
- **FR-001.3**: 定义完整的类型体系：`PronunciationScore`、`PhonemeScore`、`TeacherFeedback`、`SyllableBreakdown`、`PronunciationSession`、`AssessmentOptions`
- **FR-001.4**: 服务工厂在主方案不可用时自动降级到文本匹配方案，降级过程对上层透明

### 验收标准
- [ ] 接口定义完整，TypeScript 类型无 `any`
- [ ] 工厂函数可根据配置创建不同 Provider
- [ ] 主方案不可用时自动降级，上层无感知

---

## FR-002: 讯飞口语评测（ISE）后端实现

### 描述
接入讯飞口语评测 API，实现音素级英语发音评分。

### 要求
- **FR-002.1**: 实现 `IflytekISEProvider`，调用讯飞口语评测 API
- **FR-002.2**: 支持英文单词/短句的发音评测
- **FR-002.3**: 返回总分（0-100）、音素级评分数组、流利度评分、完整度评分
- **FR-002.4**: 设置 `age=child` 参数启用幼儿评测模式
- **FR-002.5**: 超时处理（3 秒超时自动降级到文本匹配）
- **FR-002.6**: 错误处理（API 错误码映射 + 重试机制，最多 1 次重试）

### 验收标准
- [ ] 单词 "apple" 的发音可获得音素级评分
- [ ] 幼儿模式下评分比标准模式更宽容
- [ ] API 超时 3 秒后自动降级
- [ ] API Key 通过环境变量配置，不硬编码

---

## FR-003: 文本匹配降级方案

### 描述
当讯飞 API 不可用时，使用 STT 识别结果与期望文本的匹配度作为评分依据。

### 要求
- **FR-003.1**: 实现 `TextMatchFallbackProvider`
- **FR-003.2**: 使用现有 Paraformer STT 将录音转为文字
- **FR-003.3**: 计算 Levenshtein 编辑距离 + 归一化匹配度（0-100）
- **FR-003.4**: 结合 STT 置信度加权最终分数
- **FR-003.5**: 降级模式下不提供音素级评分（`phonemeScores` 返回空数组）

### 验收标准
- [ ] 完全匹配的文本得分 ≥ 90
- [ ] 部分匹配按比例得分
- [ ] 完全不匹配但有内容得分 ≥ 40（宽容策略）
- [ ] 无录音内容得分为 0（系统提示"没有听到声音哦"）

---

## FR-004: 幼儿宽容评分策略

### 描述
实现适合 4-5 岁幼儿的宽容评分调整策略。

### 要求
- **FR-004.1**: 定义 `CHILD_SCORING_ADJUSTMENTS` 常量对象
- **FR-004.2**: 最低可接受分数为 40 分（低于 40 视为"没说"）
- **FR-004.3**: 星级阈值：1 星 [40-54]、2 星 [55-69]、3 星 [70-84]、4 星 [85-94]、5 星 [95-100]
- **FR-004.4**: 永不给 0 星——只要检测到有效语音输入，最低给 1 星
- **FR-004.5**: 评分时忽略音调（tone）、重音（stress）、节奏（rhythm）的细微偏差
- **FR-004.6**: 重点评估首字母辅音和元音的准确性
- **FR-004.7**: 实现 `applyChildAdjustments(rawScore)` 函数，将原始评分转换为幼儿友好评分

### 验收标准
- [ ] 原始分 30 → 调整后 ≥ 40（保底 1 星）
- [ ] 原始分 60 → 调整后 ≥ 70（确保 3 星通过）
- [ ] 有效语音输入永不返回 0 星
- [ ] 无语音输入返回特殊状态（非 0 星，而是"没有听到"提示）

## FR-005: 纠音教学循环编排器

### 描述
实现渐进式纠音教学循环的状态机（PronunciationCoordinator）。

### 要求
- **FR-005.1**: 实现完整状态机，支持 6 个阶段：`initial` → `c2_retry_1` → `c2_retry_2` → `c1_drill` → `c1_final` → `completed`
- **FR-005.2**: `assess()` — 执行发音评分，根据结果决定下一步
- **FR-005.3**: `retrySlow()` — C2 慢速重试，第 1 次 TTS 语速 0.7x，第 2 次 0.5x
- **FR-005.4**: `drillSyllables()` — C1 分音节教学，拆分单词后逐段跟读评分
- **FR-005.5**: `generateFeedback()` — 根据当前阶段和评分结果从模板库拼接反馈
- **FR-005.6**: 每次评分后记录到 `attempts` 数组，追踪最佳分数
- **FR-005.7**: 所有路径最终进入 `completed` 状态，产出 `finalStars` 评定

### 验收标准
- [ ] 首次 ≥ 3 星 → 直接通过，不进入重试
- [ ] 首次 < 3 星 → 进入 C2 慢速重试
- [ ] C2 两次后仍 < 3 星 → 进入 C1 分音节
- [ ] C1 后无论评分如何 → 给出鼓励 + 最终评定
- [ ] 6 种终态均有对应反馈语

## FR-006: 英文音节拆分引擎

### 描述
将英文单词拆分为音节数组，用于 C1 分音节教学。

### 要求
- **FR-006.1**: 实现 `splitSyllables(word)` 函数，返回 `SyllableBreakdown`
- **FR-006.2**: 内置常用幼儿英语单词音节词典（200+ 个常用词预设正确拆分）
- **FR-006.3**: 词典未命中时使用规则引擎拆分（基于辅音-元音模式）
- **FR-006.4**: 返回重音音节索引

### 验收标准
- [ ] `apple` → `["ap", "ple"]`
- [ ] `elephant` → `["el", "e", "phant"]`
- [ ] `cat` → `["cat"]`（单音节不拆分）
- [ ] 词典内单词拆分准确率 100%
- [ ] 规则引擎拆分准确率 ≥ 85%

## FR-007: 温和引导型反馈模板库

### 描述
实现按星级和阶段的反馈模板库，支持变量替换。

### 要求
- **FR-007.1**: 按 5 个星级分类，每级 3-5 条模板（随机选取避免重复）
- **FR-007.2**: 按阶段分类：`initial`（首次）、`afterRetry`（重试后）、`afterDrill`（分音节后）、`finalEncourage`（最终鼓励）
- **FR-007.3**: 支持模板变量：`{word}`（单词）、`{goodPart}`（做对的部分）、`{focusPart}`（需改进部分）、`{syllable}`（当前音节）
- **FR-007.4**: 分音节教学专用模板：开场引导语、每段跟读提示语、合并练习引导语、成功鼓励语
- **FR-007.5**: 所有反馈遵循**三明治法则**：肯定 → 引导 → 鼓励

### 验收标准
- [ ] 每个星级 + 阶段组合至少 3 条模板
- [ ] 模板变量正确替换
- [ ] 连续 3 次同一场景不出现重复反馈

## FR-008: 发音练习 UI 组件

### 描述
实现发音练习相关的 4 个 UI 组件。

### 要求

#### FR-008.1: StarRating 星星评分组件
- 输入 1-5 星，展示对应数量的亮星 + 暗星
- 评分揭晓时星星逐个点亮动画（Framer Motion）
- 幼儿友好：大尺寸星星（≥ 40px）、明亮金色

#### FR-008.2: SyllableHighlight 音节高亮组件
- 展示单词的音节拆分（视觉分隔符 `·`）
- 当前练习的音节高亮（放大 + 变色）
- 已完成的音节显示对应小星星
- 支持从左到右逐段推进

#### FR-008.3: PronunciationFeedback 评分反馈组件
- 组合 StarRating + TeacherFeedback 反馈语
- AI 老师头像 + 气泡式反馈语展示
- 反馈语同时通过 TTS 播放
- "再试一次"/"继续"按钮

#### FR-008.4: PronunciationDrill 纠音练习页面
- 整合 VoiceRecorder（已有）+ VoicePlayer（已有）+ 上述新组件
- 展示当前练习单词（大字、配图）
- 按纠音循环状态自动切换 UI
- C1 分音节模式下展示拍手引导动画

### 验收标准
- [ ] StarRating 正确展示 1-5 星 + 点亮动画
- [ ] SyllableHighlight 正确高亮当前音节
- [ ] PronunciationFeedback 展示反馈语 + 按钮可交互
- [ ] PronunciationDrill 完整走通纠音循环 UI 流程

---
