## MODIFIED Requirements

### Requirement: Multiple-choice question UI
The PlacementTestPage SHALL display 4-choice questions with large, touch-friendly option buttons styled in the Sunny Playground warm-color theme.

#### Scenario: Displaying a question
- **WHEN** a multiple-choice question is presented
- **THEN** the screen shows: question stem at the top (large friendly font), 4 option buttons in a 2×2 grid layout
- **AND** each option button displays the option emoji (large) and text (readable font)
- **AND** the progress bar shows current question number / total questions

#### Scenario: Selecting an answer
- **WHEN** the child taps an option button
- **THEN** the selected option is highlighted with a press animation
- **AND** after 0.3s, feedback is shown: ✓ green bounce animation for correct, gentle ✗ for incorrect
- **AND** the correct answer is always revealed (highlighted in green) after selection

#### Scenario: Transitioning between Phase 1 and Phase 2
- **WHEN** Phase 1 is completed and Phase 2 is needed
- **THEN** a transition screen appears: "小星老师正在出题..." with a thinking/writing animation
- **AND** once Phase 2 questions are ready (AI generated or fallback), the transition smoothly fades into the first Phase 2 question

### Requirement: Phase transition loading state
The system SHALL show an engaging loading animation during Phase 2 question generation to maintain the child's attention.

#### Scenario: AI question generation in progress
- **WHEN** Phase 2 questions are being generated by AI
- **THEN** the screen shows an animated character (小星老师 mascot) with speech bubble "让我想想更好的题目..."
- **AND** a gentle pulsing progress indicator is displayed
- **AND** the loading state lasts no more than 10 seconds (timeout fallback to preset questions)

### Requirement: Assessment result display
The result page SHALL show a detailed breakdown including Phase 1 and Phase 2 performance.

#### Scenario: Two-phase result display
- **WHEN** the assessment completes with both phases
- **THEN** the result page shows: overall star rating (1-5), per-module mastery indicators (emoji-based), total correct/total questions ratio
- **AND** a friendly summary message appropriate for the child's performance level

### Requirement: Timer display per question
Each question SHALL display a 30-second countdown timer in a child-friendly format.

#### Scenario: Timer counting down
- **WHEN** a new question appears
- **THEN** a circular progress timer starts from 30 seconds
- **AND** the timer uses warm colors (green → yellow → orange as time decreases)
- **AND** at 5 seconds remaining, a gentle pulse animation draws attention
