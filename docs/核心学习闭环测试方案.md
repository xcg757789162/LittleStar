### Phase 3：学习进度持久化验证

**目标**：验证课堂完成后，学习数据正确写入数据库所有相关表。

#### 3.1 数据库多表验证

> 课堂完成后 `onSessionEnd()` 会写入以下表：

| 表名 | 验证内容 | 查询方式 |
|------|---------|---------|
| `daily_sessions` | 新增一条当日学习会话记录 | `child_id + created_at = 今天` |
| `mastery_records` | 知识点掌握度记录 | `child_id + 最近更新` |
| `classroom_history` | 课堂历史记录（由 `ReviewLearningService.saveClassroomHistory` 写入） | `child_id + subject = math` |
| `classroom_snapshots` | 课堂快照数据 | 关联 `classroom_history.id` |
| `mastery_snapshots` | 掌握度周期快照 | `child_id + 最近创建` |
| `achievements` | 成就解锁记录（可能为空，取决于是否触发成就条件） | `child_id` |

#### 3.2 API 验证脚本

```bash
# 获取 child_id（从登录后的 API 响应中获取）
# 假设 CHILD_ID 和 TOKEN 已获取

# 1. daily_sessions — 今日学习记录
curl -H "Authorization: Bearer $TOKEN" \
  "http://localhost/api/daily_sessions?child_id=eq.$CHILD_ID&order=created_at.desc&limit=1"

# 2. mastery_records — 掌握度记录
curl -H "Authorization: Bearer $TOKEN" \
  "http://localhost/api/mastery_records?child_id=eq.$CHILD_ID&order=updated_at.desc&limit=5"

# 3. classroom_history — 课堂历史
curl -H "Authorization: Bearer $TOKEN" \
  "http://localhost/api/classroom_history?child_id=eq.$CHILD_ID&order=created_at.desc&limit=1"

# 4. classroom_snapshots — 关联快照
curl -H "Authorization: Bearer $TOKEN" \
  "http://localhost/api/classroom_snapshots?history_id=eq.$HISTORY_ID"
```

## 三、异常场景与降级测试

### 3.1 课堂加载失败降级

| 场景 | 触发方式 | 预期行为 |
|------|---------|---------|
| iframe 加载超时 | OpenMAIC 服务不返回 classroomUrl | 15 秒后自动降级到 `ClassroomView` |
| 无缓存课堂 | `classroom_cache` 为空 | 显示"暂无课堂数据" + "🔄 重试"按钮 |
| ClassroomView 也无数据 | 后端完全不可用 | 空状态提示 |

### 3.2 网络中断场景

| 场景 | 预期行为 |
|------|---------|
| 答题过程中网络断开 | 答题数据暂存本地 store，网络恢复后同步 |
| 退出时网络断开 | `onSessionEnd` 写入失败，下次登录可能丢失本次记录 |

### 3.3 OpenMAIC 服务故障

| 场景 | 预期行为 |
|------|---------|
| OpenMAIC 容器挂掉 | 首页显示"课程准备中"，学习页显示空状态 |
| 生成超时（>15 分钟） | `pollUntilComplete` 最多 180 次轮询，超时后标记失败 |

## 四、数据验证 SQL（直接数据库查询备用）

> 通过 Docker exec 进入 PostgreSQL 直接查询，作为 API 验证的 backup

```sql
-- 进入数据库
-- docker exec -it littlestar-postgres psql -U postgres -d littlestar

-- 1. 查看课堂缓存
SELECT id, child_id, subject, expires_at, created_at 
FROM api.classroom_cache 
WHERE child_id = {CHILD_ID} 
ORDER BY created_at DESC;

-- 2. 查看今日学习会话
SELECT id, child_id, subject, questions_completed, accuracy, duration_minutes, created_at
FROM api.daily_sessions 
WHERE child_id = {CHILD_ID} 
  AND created_at::date = CURRENT_DATE
ORDER BY created_at DESC;

-- 3. 查看掌握度记录
SELECT id, child_id, knowledge_node_id, mastery_level, updated_at
FROM api.mastery_records 
WHERE child_id = {CHILD_ID}
ORDER BY updated_at DESC 
LIMIT 10;

-- 4. 查看课堂历史
SELECT id, child_id, subject, classroom_id, created_at
FROM api.classroom_history 
WHERE child_id = {CHILD_ID}
ORDER BY created_at DESC 
LIMIT 5;

-- 5. 查看成就
SELECT id, child_id, achievement_type, created_at
FROM api.achievements 
WHERE child_id = {CHILD_ID}
ORDER BY created_at DESC;
```

## 五、测试执行策略

### 5.1 执行顺序

```
P1（课堂生成）→ P2（完成学习）→ P3（持久化验证）→ P4（退出重登）→ P5（复习）→ P6（继续学习）
```

> 严格按顺序执行，每个 Phase 的前置条件依赖前一 Phase 的输出。

### 5.2 数据依赖链

```
登录 → childId → classroom_cache 查询
  ↓
选科 → startFlow(subject) → 缓存课堂加载
  ↓
答题 → handleClassroomAnswer → store 记录
  ↓
完成 → handleClassroomComplete → onSessionEnd → DB 写入
  ↓
退出 → 清除 token → 重新登录 → restoreAuth → 恢复数据
```

### 5.3 超时与重试策略

| 操作 | 超时 | 重试 |
|------|------|------|
