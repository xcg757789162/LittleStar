## 一、产品定位与调性

### 1.1 品牌调性

- **核心关键词**：温暖、有趣、鼓励、成长
- **视觉风格**：明亮温暖的色调，圆润可爱的图形，太空/星辰主题
- **情感定位**：像一位温柔耐心的幼儿园老师，永远鼓励、从不批评
- **Slogan**：「每个孩子，都是独一无二的小星辰」

### 1.2 设计原则

| 原则 | 说明 |
|------|------|
| 🎯 极简操作 | 4-5岁孩子能独立操作，最多2步完成任何动作 |
| 🎨 视觉优先 | 图片+动画为主，文字为辅，关键信息语音播报 |
| 🌈 正面引导 | 没有"错误"只有"再试一次"，永远鼓励 |
| 🎮 游戏化 | 学习=星际冒险，知识点=星球，完成=收集星星 |
| 🔒 安全围栏 | 无广告、无外链、无社交、无付费陷阱 |
| ♿ 包容设计 | 大按钮、高对比、语音引导，照顾不同能力的孩子 |

## 二、信息架构

### 2.2 核心用户流程

#### 流程1：首次使用

```
打开App → 欢迎动画 → AI老师自我介绍（语音）
    → "我们来做个小游戏，看看你已经会了什么！"
    → 入学自适应测评（10-15题，动态调整难度，游戏化）
    → "太棒了！我知道从哪里开始教你了！"
    → 生成个性化学习计划
    → 展示星球地图（你的学习旅程，分区域逐步揭示）
    → 开始第一课（先从儿歌/对话听说启蒙开始）
```

#### 流程2：日常学习

```
打开App → AI老师问候 → "今天我们来学习[知识点]！"
    → 热身：儿歌/TPR动一动（2-3分钟）
    → 模块1教学（动画+语音讲解）
    → 模块1练习（互动题目+跟读）
    → 模块1评估（6-8题）
        ├── ≥75% → 🎉庆祝动画 + 获得星星 → 模块2
        └── <75% → "没关系，这个我们慢慢来！" → 标记🌙 → 仍可进入模块2
    → 模块2 ...
    → [可选] 亲子小任务 → "和爸爸妈妈一起xxx！"
    → 学习总结 → "你今天太棒了！明天继续星际冒险！"
    → 家长提示：今天学了什么，怎么在家配合巩固
```

#### 流程3：补救教学（软门控）

```
评估未达标（<75%）
    → 标记为"需复习🌙"
    → AI老师："这个有点难对不对？没关系，我们先去探索新星球！"
    → 继续下一模块（不阻塞）
    
    → 后续学习中自动穿插补救：
        → 补救轮次1（换教学方式：如动画→互动游戏）
            → 重新评估
                ├── 达标 → 🌙→⭐ 标记已掌握
                └── 未达标 → 补救轮次2（降低难度，拆分知识点）
                    → 重新评估
                        ├── 达标 → 标记已掌握
                        └── 未达标 → 补救轮次3（最基础方式）
                            → 重新评估
                                ├── 达标 → 标记已掌握
                                └── 未达标 → "这个我们慢慢来，之后还会遇到它的！"
                                    → 标记"需关注📌" → 持续追踪
```

## 三、UI/UX 设计规范

### 3.1 色彩系统

```
主色调（星辰蓝）
├── Primary:     #4A90D9  — 主按钮、进度条、重要元素
├── Primary Light: #7BB3E8 — 悬停、次要元素
└── Primary Dark:  #2E6CB5 — 文字、强调

辅助色（温暖系）
├── Accent Gold:   #FFD700 — 星星、金币、成就
├── Accent Orange: #FF9F43 — 奖励、特殊元素
├── Accent Green:  #4CD964 — 正确、达标、完成
├── Accent Pink:   #FF6B9D — 爱心、鼓励

中性色
├── Background:    #F8FAFF — 页面背景（浅蓝白）
├── Card:          #FFFFFF — 卡片背景
├── Text Dark:     #2C3E50 — 主要文字
├── Text Light:    #95A5A6 — 次要文字

语义色
├── Success:       #4CD964 — 答对、达标
├── Encourage:     #FFD700 — 鼓励（替代传统的"错误"红色）
└── Info:          #5AC8FA — 提示信息

⚠️ 重要：不使用红色表示错误！
   4-5岁孩子对红色=错误会产生挫败感
   用金色"再试一次"替代红色"错误"
```

### 3.2 字体系统

```
中文字体：思源黑体（Noto Sans SC）
英文字体：Nunito / Fredoka One（圆润可爱）

字号层级（基于iPad分辨率）：
├── 超大标题：  48px — 数字、关键词展示
├── 大标题：    36px — 页面标题
├── 标题：      28px — 模块标题
├── 正文大：    24px — 教学内容文字
├── 正文：      20px — 说明文字
└── 辅助：      16px — 标签、提示

⚠️ 最小字号不低于 16px（幼儿视力保护）
```

### 3.3 组件设计

#### 按钮

```
尺寸：最小 88×88pt（iPad触控友好）
圆角：24px（大圆角，可爱感）
状态：
├── 默认：饱和色 + 轻微阴影
├── 按下：颜色加深 + 缩放0.95 + 触感反馈
├── 禁用：灰色 + 不可点击
└── 成功：绿色 + ✓ 动画
```

#### 卡片

```
圆角：20px
阴影：0 4px 12px rgba(0,0,0,0.08)
内边距：24px
背景：白色
边框：无（用阴影区分层级）
```

#### 进度条

```
高度：16px（圆角两端）
背景：#E8EDF2
填充：渐变（Primary → Accent Gold）
动画：填充时有流水效果
星星标记：关键节点显示星星图标
```

#### 星星/金币

```
星星：五角星，金色(#FFD700)，获得时有旋转+放大动画
金币：圆形，金色渐变，中间有"★"图案
数字：使用 Fredoka One 字体，白色描边
```

### 3.4 动画规范

```
过渡动画：
├── 页面切换：slide + fade，300ms，ease-in-out
├── 元素出现：fade-in + scale，200ms
└── 元素消失：fade-out，150ms

教学动画：
├── 字母出现：手写描红动画，1-2秒
├── 物品展示：bounce进入 + 轻微浮动
└── 场景切换：星空飞行过渡

奖励动画：
├── 获得星星：星星从天而降 + 旋转 + 放大 → 飞入计数器
├── 答对：彩色粒子爆炸 + "✨太棒了！" 弹出
├── 升级：全屏烟花 + 等级徽章展示
└── 需复习变已掌握：月亮→星星变化动画
```

### 3.5 音效规范

```
交互音效：
├── 按钮点击：轻柔的"叮"声
├── 拖拽放置：柔和的"咚"声
├── 答对：欢快的"叮叮叮~"上升音阶
├── 鼓励重试：温柔的"咚~"单音
└── 翻页/切换：轻柔的"嗖"声

奖励音效：
├── 获得星星：清脆的魔法音效
├── 获得金币：金币落地声
├── 升级：号角+烟花声
└── 连续学习：欢快的短旋律

环境音效：
├── 学习中：轻柔的背景音乐（可选开关）
├── 星球地图：太空环境音
└── 成就中心：欢快的背景旋律
```

## 五、AI老师人设

### 5.1 基本信息

| 属性 | 设定 |
|------|------|
| 名字 | 星星老师（Star Teacher） |
| 形象 | 穿着星空斗篷的可爱女性卡通形象，头上有星星发饰 |
| 声音 | 温柔女声，语速偏慢，吐字清晰，带微笑感 |
| 语言 | 中英双语，教英语时英文发音标准，中文解释亲切 |
| 性格 | 温柔、耐心、鼓励、有趣 |

### 5.2 对话风格

#### 教学时

```
✅ "我们来认识一个新朋友！这是字母D，D-D-Dog，小狗狗！"
✅ "看这个字母，它长得像什么呀？像不像一个半圆形的门？"
✅ "跟我一起说：D~ 很好！再来一次！"

❌ "请记住字母D的发音是/d/。"  （太学术，不适合4岁）
❌ "注意，D和B不要搞混。"      （负面引导，容易真的搞混）
```

#### 答对时

```
✅ "哇！太棒了！你答对了！⭐"
✅ "你真是太聪明了！这颗星星送给你！"
✅ "耶！你已经是字母D的小专家了！"
```

#### 答错/未达标时（永远不说"错"）

```
✅ "嗯~这个不太对哦，没关系，我们再看一次！"
✅ "差一点点就对了！再试试看？"
✅ "这个有点难对不对？我们换个有趣的方式来学！"
✅ "慢慢来，不着急，我们一起再看看！"

❌ "错了！"
❌ "不对！"
❌ "你怎么还不会？"
```

#### 补救教学时

```
轮次1："我们来玩个游戏吧！这次我们用唱歌的方式来学！"
轮次2："没关系！我们把它拆开来，一步一步看！"
轮次3："来，我们用最简单的方式，跟着我的手指一起！"
超过3轮："这个我们慢慢来，之后还会遇到它的，不用担心！"
```

### 5.3 AI老师语音规范

| 场景 | 语言 | 语速 | 情感 |
|------|------|------|------|
| 中文讲解 | 普通话 | 较慢（0.8x） | 温柔亲切 |
| 英文教学 | 美式英语 | 慢速（0.7x） | 清晰标准 |
| 鼓励赞美 | 中文 | 正常（1.0x） | 开心兴奋 |
| 引导提示 | 中文 | 较慢（0.8x） | 耐心鼓励 |
| 儿歌歌词 | 英文 | 正常（1.0x） | 活泼韵律 |

## 六、激励系统详细设计

> ⚠️ **设计原则**：以内在动机为核心，外部激励为辅。遵循自我决定理论（SDT），强调自主感（选择学什么）、胜任感（我学会了！）、归属感（和星星老师一起冒险）。避免过度外部奖励削弱内在学习动机。

### 6.1 核心激励：即时庆祝动画（最重要）

| 场景 | 反馈 |
|------|------|
| 答对题目 | 彩色粒子爆炸 + "太棒了！" + 星星飞入 |
| 完成模块 | 星球点亮动画 + AI老师鼓掌 |
| 首次掌握 | 特殊星球绽放动画 + "你成为XX小专家了！" |
| 掌握需复习内容 | 月亮变星星动画 + "你做到了！" |

### 6.2 星星系统（简化）

| 获得方式 | 数量 |
|---------|------|
| 答对练习题 | +1⭐ |
| 完成一个模块 | +3⭐ |
| 首次达标（掌握率≥75%） | +5⭐ |
| 语音跟读评分≥4星 | +2⭐ |
| 完成整课学习 | +5⭐ |

### 6.3 等级系统（简化为4级）

| 等级 | 名称 | 所需经验 | 解锁内容 |
|------|------|---------|---------|
| Lv.1 | 小火苗 🔥 | 0 | 基础主题 |
| Lv.2 | 小星星 ⭐ | 300 | 新主题背景 + AI老师新表情 |
| Lv.3 | 超级星 💫 | 800 | 特殊动画效果 |
| Lv.4 | 星辰守护者 🌠 | 2000 | 全部解锁 |

经验值 = 星星数 × 10

### 6.4 金币系统（Phase 1 简化）

- 累积10颗星星自动转换为1金币
- Phase 1 暂不设消费出口（未来可增加虚拟商店）
- 金币以图形化展示，不作为核心激励

### ~~6.5 连续打卡奖励~~（已移除）

> 4岁孩子没有"连续天数"的时间概念，连续打卡机制对孩子无意义，反而增加家长焦虑和压力。

## 七、题目类型设计

### 7.1 支持的题目交互类型

| 类型 | 描述 | 适用场景 | 操作方式 | Phase |
|------|------|---------|---------|-------|
| 点击选择 | 从2-4个选项中点击正确答案 | 认读、辨认 | 点击 | P0 |
| 拖拽匹配 | 将左侧元素拖到右侧对应位置 | 字母-图片匹配 | 拖拽 | P0 |
| 语音跟读 | 听AI示范后跟读，**点击自动录制** | 发音练习 | 点击 | P0 |
| 手指描红 | 在屏幕上沿描红线条书写，**仅体验不评分** | 字母书写体验 | 手指画 | P0 |
| 找不同 | 从一组中找出不同的 | 辨别能力 | 点击 | P0 |
| 涂色/连线 | 按提示涂色或连线 | 趣味巩固 | 手指画 | P1 |
| 排序题 | 拖拽元素排成正确顺序 | 字母顺序 | 拖拽 | **P2**（推迟） |

> ⚠️ **手指描红说明**：4岁幼儿精细动作发育未成熟，书写仅作为体验环节，不计入评估分数。提供描红引导线和动画示范。  
> ⚠️ **排序题推迟说明**：排序需要较强的工作记忆能力，4岁偏难，推迟到Phase 2（适合5岁+）。

### 7.2 题目难度自适应

```
初始难度：根据入学测评结果设定

动态调整规则：
├── 连续3题答对 → 难度+1（增加选项数/减少提示）
├── 连续2题答错 → 难度-1（减少选项数/增加提示）
├── 响应时间<3秒连续3次 → 太简单，难度+1
└── 响应时间>15秒 → 可能困难，给提示

难度维度：
├── 选项数量：2个 → 3个 → 4个
├── 提示程度：有图片提示 → 仅文字 → 无提示
├── 干扰项相似度：完全不同 → 部分相似 → 高度相似
└── 时间要求：无限时 → 宽松计时 → 标准计时
```

## 八、iPad 适配规范

### 8.1 屏幕适配

```
主要目标：iPad（横屏）
├── iPad 10代：2360 × 1640 (264 ppi)
├── iPad Air：2360 × 1640 (264 ppi)
├── iPad Pro 11：2388 × 1668 (264 ppi)
└── iPad Pro 12.9：2732 × 2048 (264 ppi)

设计基准：1024 × 768 逻辑像素（横屏）
响应策略：弹性布局 + 最大内容宽度限制

方向：强制横屏（Landscape）
原因：
├── 教学内容展示空间更大
├── 更接近"黑板"/"课堂"体验
└── 适合书写练习的横向空间
```

### 8.2 触控区域

```
最小可点击区域：88 × 88 pt（Apple HIG推荐44pt的2倍）
元素间距：至少 16pt（防误触）
拖拽区域：元素实际区域 + 20pt 扩展热区
手势支持：
├── 点击（Tap）
├── 拖拽（Drag）— 匹配题
├── 手指滑动（Swipe）— 描红
├── 三指长按3秒 — 进入家长设置（安全手势）
└── 不使用：双指缩放、多指手势（对4岁太复杂）
    不使用：长按录音（改为点击自动录制）
```

## 九、特殊场景处理

### 9.1 孩子离开/中断

```
场景：学习过程中孩子离开
处理：
├── 30秒无操作 → AI老师温柔提醒："还在吗？我们继续吧！"
├── 60秒无操作 → 自动暂停，保存进度
├── 关闭App → 自动保存所有状态
└── 重新打开 → "欢迎回来！我们从刚才的地方继续！"
```

### 9.2 孩子情绪低落（连续答错）

```
场景：连续3次以上未答对
处理：
├── 自动降低难度
├── AI老师安慰："没关系的，这个确实有点难！"
├── 插入一个简单的互动游戏（转移注意力）
├── 然后用更简单的方式重新教
└── 绝不出现"你又错了"类的表述
```

### 9.3 学习时间过长

```
场景：连续学习超过30分钟
处理：
├── AI老师："你今天学了好多啊！要不要休息一下眼睛？"
├── 建议休息（但不强制）
├── 如果继续，每10分钟再次提醒
└── 家长可在设置中调整时间限制
```
