# Frontend Design Skill

> Based on [Anthropic's official frontend-design plugin](https://github.com/anthropics/claude-code/tree/main/plugins/frontend-design) by Prithvi Rajasekaran & Alexander Bricken.

Generates distinctive, production-grade frontend interfaces that avoid generic AI aesthetics.

## What It Does

This skill is automatically triggered for frontend work. Creates production-ready code with:

- Bold aesthetic choices
- Distinctive typography and color palettes
- High-impact animations and visual details
- Context-aware implementation

## OpenMAIC Customizations

This version includes project-specific addendum for our 2-8 year old children's English learning app:

- Child-friendly touch targets (88×88pt minimum)
- Playful, rounded typography
- Bright, warm, saturated color schemes
- Essential engagement animations (star bursts, confetti, bouncing characters)
- Immediate visual + audio feedback on every interaction
- Safety-first design (no external links, no ads, no scary imagery)

## Usage

The skill activates automatically when building UI components. Example prompts:

```
"Create the phonics lesson card component"
"Build the achievement celebration animation"
"Design the parent dashboard"
"Implement the alphabet learning screen"
```
